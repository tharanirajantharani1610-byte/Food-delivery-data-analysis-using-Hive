Docker Architecture & Service Mapping

All services run in isolated Docker containers via docker-compose.yml. Zero manual Hadoop installation or local configuration required on Windows.

Container Role Exposed Port Status
hive-server HiveServer2 & Hive CLI 10000 (JDBC), 10002 (UI) Active
hive-metastore Standalone Metastore Daemon 9083 Active
hive-metastore-postgresql PostgreSQL Metastore DB 5432 Active
namenode HDFS Master Node 50070 (Web UI) Active
datanode HDFS Worker Node 50075 (Web UI) Active

Essential Windows Commands

# Start cluster
docker compose up -d

# Verify containers
docker compose ps

# Access Hive CLI inside container
docker exec -it hive-server hive

# Execute HiveQL script directly
docker exec -i hive-server hive -f /opt/hive-scripts/analysis.sql
